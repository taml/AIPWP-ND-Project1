Question 3: Describe what we did to the pandas DataFrame in order to change how the outputs are reflected.

To change how the DataFrame is output a few options were configured.
A max_columns option was configured which makes sure all data columns are displayed.
A width option, which provides more or less space for columns depending on the value used and a max_colwidth option which sets the width of columns and can make them bigger or smaller depending on preference.
After making these configuration changes the data now fits within the output container, with a little overlapping between columns.
Now also instead of seeing 5 rows, 10 rows are displayed.
